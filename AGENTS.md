# Working agreement

Applies to Codex, Claude, and other contributors.

- Keep the application runnable as a static site with no mandatory build step unless the user approves a tooling change.
- Work on focused branches; avoid overwriting another contributor's uncommitted work. Review the current diff before editing.
- Preserve the imported baseline and project provenance. Explain changes in commit messages and pull requests.
- Separate visual approximations from scientifically validated claims. Label tuned physics honestly.
- Verify relevant behavior before claiming a fix. JavaScript syntax checks do not verify WebGL shaders or visual quality.
- For visual changes, inspect the rendered result and desktop/narrow layouts when browser access is available.
- Do not publish, change hosting, add credentials, or assign a license without user authorization.
- Keep API keys, local configuration, caches, and generated scratch files out of Git.
